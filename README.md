# AllChrono
AllChrono is a marketplace for buying and selling watches. This is a small, self-contained slice of the kind of work you’d do on our mobile team. It’s deliberately open-ended — there’s more than one good way to do it, and we’re interested in the choices you make.


## Project Overview

I created two separate projects to demonstrate my experience in both **Native iOS** and **Cross-Platform Flutter** development.

### 1. Native iOS Project
- Developed using **Swift** and native iOS technologies.
- Focused exclusively on the **iOS platform**.
- Follows **Clean Architecture** and the **MVVM design pattern**.

### 2. Flutter Project
- Developed using **Flutter** and **Dart**.
- Includes both **Android and iOS** implementations.
- Follows **Clean Architecture** and the **MVVM design pattern**.

By maintaining two separate projects, you can review my experience and coding practices in both **Native iOS** and **Flutter** development.
